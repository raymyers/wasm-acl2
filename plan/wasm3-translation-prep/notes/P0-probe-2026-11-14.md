# Baseline probe of the unmodified pipeline on WASM 2.0 and 3.0

- Milestone: P0 (baseline; taken before any prep change)
- Date: 2026-11-14
- Repo commit: 7b513d8 (translator as of wasm1 T6), with the working tree's
  uncommitted T7 files, which the probe does not touch
- SpecTec: `WebAssembly/spec@943c5df` (the flake pin), `spectec 0.5`
- Status: final
- Feeds wasm3 plan: probe table, gap list
- Incorporated in wasm3 plan: no

## Summary

Stock SpecTec elaborates 3.0. The schema check fails only on 3 text-grammar
literals. The translator's compile phase crashes on one notation relation;
with it skipped it yields 1,268 events and 110 stubs (69 text grammars, 41
others). Nothing from 2.0 or 3.0 was certified or executed. The analysis of
these numbers is `../plan.md` §1-§3; this note holds the evidence.

## Findings

All figures in `../plan.md` §1 come from the files below. Points that are in
the data but not spelled out in plan.md:

- The 1.0 config was used with its `:rel-override` (`Module_ok`) and
  `:il-patch` (`Bmodule`) entries removed; every other entry was left in,
  including ones whose targets do not exist in 3.0 (W5).
- The 3.0 error log holds the errors of the `:fun` attempt for every relation
  that ended as a stub (W3). Do not read root causes for the typing groups
  from it.
- `:incomplete` in the summaries lists rules dropped from split variants
  during attempts, including attempts that were later discarded.
- 2.0's builtin count of 65 in the summary includes config overrides; the
  source has 63 `hint(builtin)`.
- Phase 1 compile time for 3.0: 0.47 s. `mangle-table`: 0.25 s.

## Open questions

- Whether `len = ||BX||` still elaborates to `len = 0` in the 3.0 IL (S10).
- Whether the generated 3.0 binary parser accepts real modules (P5).

To regenerate the inputs (from `translate/`, inside `nix develop ..`):

```bash
S=$(nix build ..#spectec --no-link --print-out-paths)/bin/spectec
SRC=$(nix eval --raw --impure --expr \
  '(builtins.getFlake (toString ./..)).inputs.wasm-spec.outPath')
for v in 2.0 3.0; do
  $S --ast --all-passes $SRC/specification/wasm-$v/*.spectec > SCRATCH/wasm-$v.il.sexp
done
acl2 < schema-check.lsp        # after replacing SCRATCH with a real directory
acl2 < translate-3.0.lsp
```

P0 replaces these scripts with `make -C translate probe SPEC=<v>`.
